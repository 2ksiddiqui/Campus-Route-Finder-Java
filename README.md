# Campus Route Finder — Java

An interactive campus navigation desktop application developed using Java Swing and Dijkstra's shortest-path algorithm.

## Overview

Campus Route Finder helps users find efficient walking routes between campus buildings using graph-based pathfinding.

The application features an interactive campus map, route visualization, and tools for exploring and comparing routes.

## Features

- **Shortest-Path Calculation:** Uses Dijkstra's algorithm to calculate efficient routes between connected buildings.
- **Interactive Campus Map:** Displays buildings and paths through a Java Swing graphical interface.
- **Building Search:** Allows users to search for and select campus buildings.
- **Route Visualization:** Highlights selected routes on the map.
- **Walking Estimates:** Displays route distances and estimated walking times.
- **Route History:** Keeps track of previously calculated routes.
- **Route Comparison:** Allows users to compare different routes.
- **Exporting:** Saves route information to a text file.

## Technologies Used

- Java
- Java Swing
- Dijkstra's Algorithm
- Graph Algorithms
- Object-Oriented Programming

## How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the Java source file:

   `javac CampusRouteFinderJava.java`

5. Run the application using its main class:

   `java CampusRouteFinderJava`

**Note:** The source filename and main class name must match. Adjust the commands if your public class has a different name.
